# 🌐 Curso HTML e CSS

Repositório criado para armazenar meus estudos e exercícios do **curso de HTML5 e CSS3** do [Professor Gustavo Guanabara](https://www.cursoemvideo.com/).  
Aqui compartilho os projetos, desafios e práticas que desenvolvi ao longo das aulas — tudo com o objetivo de **aprender, treinar e evoluir** como desenvolvedor front-end. 🚀  

---

## 🧠 O que estou aprendendo

- Estrutura básica de um documento HTML  
- Utilização de tags semânticas  
- Inserção de imagens, vídeos e links  
- Estilização com CSS (cores, fontes, espaçamentos, alinhamentos, etc.)  
- Criação de layouts responsivos  
- Organização de pastas e boas práticas de código  

---

## 💻 Tecnologias utilizadas

- **HTML5**  
- **CSS3**  
- **VS Code** (editor principal)  

---

## 📂 Estrutura do repositório

Cada pasta representa um exercício ou desafio do curso.  
Os arquivos estão organizados para facilitar a navegação e o acompanhamento da minha evolução.
